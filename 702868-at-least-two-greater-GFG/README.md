# [At least Two Greater](https://www.geeksforgeeks.org/problems/at-least-two-greater-elements4625/1)
## Easy
Given an array arr of distinct elements, the task is to return an array of elements that have at least two greater elements.Examples:Input: arr[] = [2, 8, 7, 1, 5]
Output: [1, 2, 5] 
Explanation: Here we return an array contains 1, 2, 5 and we leave two greatest elements 7 &amp; 8. Input: arr[] = [7, -2, 3, 4, 9, -1]Output: [-2, -1, 3, 4]Explanation:  Here we return an array contains -2 ,  -1,  3,  4 and we leave two greatest elements 7 &amp; 9.
